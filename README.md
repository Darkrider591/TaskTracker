# TaskTracker — Локальный трекер задач

Простое приложение для управления задачами.
Работает **локально**, данные хранятся в SQLite.

## 💡 Возможности
- Добавление задач
- Перетаскивание между колонками: To Do → In Progress → Done
- Редактирование и удаление задач
- Автоматическое сохранение в файл `tasktracker.db`

## ▶️ Как запустить
1. Скачайте exe `TaskTracker.Desktop vX.X.exe`
2. Запустите `*.exe`

Использована самодостаточная сборка .exe, не требуется .NET 8 Runtime.

## 📂 Файлы
- `TaskTracker.Desktop.exe` — приложение
- `tasktracker.db` — ваша база данных (можно резервировать)

## ⚠️ Важно
- Не удаляйте `tasktracker.db` — потеряете все задачи!
- Программа не требует установки — работает из любой папки.
